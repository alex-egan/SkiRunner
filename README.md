# SkiRunner
An application for programmatically creating a day of skiing based on a list of criteria.

## Technologies Used
- [C# Web API](https://learn.microsoft.com/en-us/aspnet/core/tutorials/first-web-api?view=aspnetcore-8.0&tabs=visual-studio)
- [A* Algorithm](https://en.wikipedia.org/wiki/A*_search_algorithm)

## Getting Started with the Application
### Clone the SkiRunner Repository
### Open the Repository in Visual Studio Code
### Run the Application
Basic results will be displayed in the console.
